## Active UI project: `ui/SonicUI/`

- `src/main/` — Electron main process, download managers, network handling, updater, and IPC handlers.
- `src/preload/` — typed, restricted bridge between the main process and renderer.
- `src/renderer/` — React desktop interface and reusable components.
- `src/shared/` — shared types, IPC contracts, and protocol definitions.
- `extension/` — browser extension source and build tooling.
- `e2e/` — Playwright end-to-end tests and fixtures.
- `tests/` — focused security and unit tests.
- `scripts/` — packaging validation, SBOM generation, third-party notice generation, and release tooling.
- `patches/` — maintained dependency patches.
- `docs/` — security, feature, extension, and release documentation.
- `build/` and `resources/` — installer resources, icons, and app artwork.
- `package.json` and `package-lock.json` — scripts and locked dependency graph.

## Build output and local-only files

Build output, dependency folders, temporary test reports, and installers should normally be generated by local build commands or CI rather than tracked as source. Keep source files, lockfiles, tests, required license notices, dependency patches, and release evidence in version control.

The old root-level `build-core.ps1`, `build-preview.ps1`, and `build-cli-queue.ps1` helper scripts were removed from the tracked project. The supported build and test commands are documented in the root README; the underlying Core, App, and CLI source projects remain active.
